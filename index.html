Ejercicio 1: Raíces de una Ecuación Cuadrática

a) Descripción del problema: Dado un polinomio de segundo grado ax² + bx + c = 0, calcular el discriminante D = b² - 4ac y evaluar sus raíces.
b) Algoritmo:
  1. Leer los coeficientes a, b y c desde el formulario.
  2. Calcular el discriminante: D = (b × b) - (4 × a × c).
  3. Si D > 0, calcular las dos raíces reales.
  4. Si D = 0, calcular la raíz única.
  5. Si D < 0, mostrar que no tiene raíces reales.

b) Algoritmo:
